# Bautizo, Baby Shower y demas

Plantilla de invitacion digital estilo oceano (muestra: Baby Torres Vidal, baby shower 14.08.2027).

Dos versiones disponibles:
- `con-generador/` — el sobre muestra familia y numero de boletos via URL (`index.html?f=Familia&b=3`), generados con `generar.html`.
- `sin-generador/` — un solo enlace para todos, sin personalizacion.

Ambas comparten los mismos assets (fotos, imagenes, musica) ubicados en esta carpeta.
